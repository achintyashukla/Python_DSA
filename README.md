# Python_DSA

A collection of Data Structures and Algorithms (DSA) notes, step-by-step explanations, Python implementations, complexity analyses, and curated LeetCode problems in Jupyter Notebooks.

## Contents

### Array and String Algorithms
- [Kadane's Algorithm](Array%20and%20String%20Algorithms/Kadane_Algorithm.ipynb) — Maximum Subarray Sum intuition, step-by-step trace, Python implementations & variants, $O(n)$ time / $O(1)$ space complexity analysis, and 10 LeetCode problems.
- [2D Kadane's Algorithm](Array%20and%20String%20Algorithms/2D_Kadane_Algorithm.ipynb) — Maximum Sum Submatrix (2D-to-1D row compression), step-by-step trace, dimension-optimized Python implementations, complexity analysis, and related LeetCode problems.
